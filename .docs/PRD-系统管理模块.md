# 系统管理模块产品需求文档

## 模块概述
系统管理模块是平台的基础支撑模块，提供组织管理、用户管理、角色管理、字典管理和日志管理等系统级功能，为平台的正常运行提供基础保障。

## 功能模块

### 1. 组织管理

#### 1.1 功能描述
管理平台的组织架构，支持多层级组织结构，为用户权限和资源分配提供组织维度的管理。

#### 1.2 功能需求

**1.2.1 组织树结构**
- 树形展示组织架构
- 支持多层级组织（部门、科室、小组等）
- 支持组织节点展开/折叠
- 显示组织层级关系
- 显示组织成员数量

**1.2.2 组织创建**
- 创建根组织（顶层组织）
- 创建子组织
- 设置组织信息：
  - 组织名称
  - 组织编码
  - 组织类型
  - 组织描述
  - 负责人
  - 联系方式
  - 组织地址
- 设置父组织

**1.2.3 组织编辑**
- 修改组织信息
- 调整组织层级
- 移动组织位置
- 合并组织
- 拆分组织

**1.2.4 组织删除**
- 删除空组织（无成员、无子组织）
- 删除前检查：
  - 检查是否有子组织
  - 检查是否有成员
  - 检查是否有关联资源
- 删除确认提示
- 支持级联删除（可选）

**1.2.5 组织查询**
- 按组织名称搜索
- 按组织编码搜索
- 按组织类型筛选
- 按负责人筛选
- 显示组织详情

**1.2.6 组织成员管理**
- 查看组织成员列表
- 添加组织成员
- 移除组织成员
- 调整成员部门
- 设置部门负责人

**1.2.7 组织权限**
- 配置组织级别权限
- 设置资源访问范围
- 组织数据隔离
- 跨组织协作配置

#### 1.3 业务规则
- 组织名称在同级组织中唯一
- 组织编码全局唯一
- 根组织不可删除
- 有成员的组织不可直接删除
- 组织层级建议不超过5层

---

### 2. 用户管理

#### 2.1 功能描述
管理平台用户账号，包括用户的创建、编辑、禁用、删除以及用户信息维护。

#### 2.2 功能需求

**2.2.1 用户列表**
- 以表格形式展示所有用户
- 显示用户信息：
  - 用户名、姓名
  - 所属组织
  - 角色
  - 状态（启用/禁用）
  - 创建时间
  - 最后登录时间
- 分页展示
- 支持排序

**2.2.2 用户搜索与筛选**
- 按用户名搜索
- 按姓名搜索
- 按手机号搜索
- 按邮箱搜索
- 按组织筛选
- 按角色筛选
- 按状态筛选（启用/禁用）

**2.2.3 创建用户**
- 填写用户基本信息：
  - 用户名（必填，唯一）
  - 姓名（必填）
  - 手机号（必填）
  - 邮箱
  - 性别
  - 所属组织（必填）
  - 工号
  - 职位
- 设置登录密码（初始密码）
- 分配角色
- 设置用户状态（启用/禁用）
- 上传用户头像

**2.2.4 编辑用户**
- 修改用户基本信息
- 调整所属组织
- 调整用户角色
- 启用/禁用用户
- 重置用户密码
- 更换用户头像

**2.2.5 删除用户**
- 删除用户账号
- 删除前确认
- 检查用户关联资源
- 逻辑删除（可选）
- 删除操作记录

**2.2.6 用户详情**
- 查看用户完整信息
- 查看用户角色列表
- 查看用户权限
- 查看用户所属组织
- 查看用户创建的资源
- 查看用户操作日志

**2.2.7 批量操作**
- 批量导入用户
- 批量导出用户
- 批量启用/禁用
- 批量分配角色
- 批量调整组织

**2.2.8 用户权限查看**
- 查看用户拥有的菜单权限
- 查看用户拥有的按钮权限
- 查看用户数据权限范围
- 权限来源追溯（直接分配/角色继承）

#### 2.3 业务规则
- 用户名全局唯一
- 手机号全局唯一
- 邮箱全局唯一（如填写）
- 用户必须属于至少一个组织
- 禁用用户无法登录
- 删除用户不影响历史数据

### 3. 角色管理

#### 3.1 功能描述
管理平台的角色体系，通过角色为用户批量分配权限，实现基于角色的访问控制（RBAC）。

#### 3.2 功能需求

**3.2.1 角色列表**
- 展示所有角色
- 显示角色信息：
  - 角色名称
  - 角色编码
  - 角色类型
  - 角色描述
  - 用户数量
  - 创建时间
- 角色状态标识

**3.2.2 创建角色**
- 填写角色基本信息：
  - 角色名称（必填）
  - 角色编码（必填，唯一）
  - 角色类型（系统角色/业务角色）
  - 角色描述
- 设置角色权限：
  - 选择菜单权限
  - 选择按钮权限
  - 设置数据权限范围
- 设置角色状态（启用/禁用）

**3.2.3 编辑角色**
- 修改角色基本信息
- 调整角色权限
- 启用/禁用角色
- 保存角色配置

**3.2.4 删除角色**
- 删除角色
- 删除前检查：
  - 检查是否有用户使用该角色
  - 检查系统角色不可删除
- 删除确认
- 角色删除后用户权限自动调整

**3.2.5 权限配置**
- **菜单权限配置**：
  - 树形展示所有菜单
  - 勾选授权菜单
  - 支持全选/反选
  - 支持父子联动
  - 实时预览权限范围
- **按钮权限配置**：
  - 按页面展示按钮列表
  - 勾选授权按钮
  - 批量配置
- **数据权限配置**：
  - 全部数据
  - 本组织数据
  - 本组织及下级组织数据
  - 仅本人数据
  - 自定义数据范围

**3.2.6 用户授权（角色分配给用户）**
- 进入用户授权页面
- 展示未分配该角色的用户列表
- 支持搜索和筛选
- 批量选择用户
- 确认授权
- 授权记录

**3.2.7 角色成员管理**
- 查看角色下的所有用户
- 移除用户角色
- 添加用户到角色
- 导出角色成员列表

**3.2.8 角色复制**
- 基于现有角色创建新角色
- 复制权限配置
- 修改角色信息
- 保存新角色

#### 3.3 预置角色
- **系统管理员**：拥有所有权限
- **数据管理员**：管理数据集和数据目录
- **模型管理员**：管理模型开发和部署
- **审核员**：负责审核工作
- **普通用户**：基础使用权限

#### 3.4 业务规则
- 角色名称全局唯一
- 角色编码全局唯一
- 系统角色不可删除和编辑
- 禁用角色下的用户权限自动失效
- 用户可拥有多个角色，权限取并集

### 4. 数据字典管理

#### 4.1 功能描述
管理平台中使用的各类字典数据，为下拉选择、状态标识等提供统一的数据源，便于维护和扩展。

#### 4.2 功能需求

**4.2.1 字典分类**
- 展示字典分类列表
- 创建字典分类：
  - 分类名称
  - 分类编码
  - 分类描述
  - 排序号
- 编辑字典分类
- 删除字典分类
- 启用/禁用分类

**4.2.2 字典项管理**
- 查看分类下的字典项列表
- 创建字典项：
  - 字典标签（显示值）
  - 字典键值（存储值）
  - 字典类型
  - 排序号
  - 备注说明
  - 状态（启用/禁用）
  - 扩展属性（JSON格式）
- 编辑字典项
- 删除字典项
- 启用/禁用字典项

**4.2.3 字典检索**
- 按分类名称搜索
- 按字典标签搜索
- 按字典键值搜索
- 按状态筛选

**4.2.4 字典导入导出**
- 导出字典数据（Excel）
- 导入字典数据（Excel）
- 批量更新字典
- 数据校验

**4.2.5 字典使用统计**
- 统计字典引用次数
- 查看字典使用位置
- 字典依赖分析

#### 4.3 常用字典类型
- 用户状态：启用/禁用
- 审核状态：待审核/已通过/已拒绝
- 数据类型：文本/数字/日期等
- 性别：男/女/未知
- 敏感级别：高/中/低
- 模型类型：智能体/机器学习/规则模型
- 部署状态：运行中/已停止/异常

#### 4.4 业务规则
- 字典分类编码全局唯一
- 同一分类下字典键值唯一
- 禁用的字典项不在前端展示
- 字典项修改不影响历史数据
- 系统字典不可删除

### 5. 日志管理

#### 5.1 功能描述
记录和管理平台的各类日志，包括用户登录日志和操作日志，用于审计、追溯和安全分析。

#### 5.2 登录日志

**5.2.1 日志记录**
- 记录所有登录行为：
  - 登录用户
  - 登录时间
  - 登录IP
  - 登录地点
  - 浏览器信息
  - 操作系统
  - 登录结果（成功/失败）
  - 失败原因

**5.2.2 日志查询**
- 按用户名搜索
- 按登录IP搜索
- 按时间范围筛选
- 按登录结果筛选
- 按登录地点筛选

**5.2.3 日志分析**
- 登录成功率统计
- 失败登录分析
- 异常登录告警
- 登录时段分析
- 登录地域分布

**5.2.4 日志导出**
- 导出查询结果
- 按时间范围导出
- 导出格式：Excel/CSV

#### 5.3 操作日志

**5.3.1 日志记录**
- 记录用户操作行为：
  - 操作用户
  - 操作时间
  - 操作模块
  - 操作类型（新增/修改/删除/查询）
  - 操作对象
  - 操作内容（前后对比）
  - 操作IP
  - 操作结果（成功/失败）
  - 耗时

**5.3.2 日志查询**
- 按用户搜索
- 按操作模块筛选
- 按操作类型筛选
- 按时间范围筛选
- 按操作结果筛选
- 关键词搜索

**5.3.3 日志详情**
- 查看操作详细信息
- 查看操作前后数据对比
- 查看关联日志
- 操作链路追踪

**5.3.4 日志统计**
- 用户操作频率统计
- 模块访问热度统计
- 操作类型分布
- 操作失败分析
- 高频操作排行

**5.3.5 日志导出**
- 导出查询结果
- 审计报告生成
- 定期归档

#### 5.4 日志管理

**5.4.1 日志清理**
- 设置日志保留策略
- 自动清理过期日志
- 手动清理日志
- 日志归档

**5.4.2 日志告警**
- 异常操作告警
- 敏感操作提醒
- 高频操作预警
- 失败操作统计

**5.4.3 日志审计**
- 审计日志完整性
- 审计日志真实性
- 审计报告生成
- 合规性检查

#### 5.5 业务规则
- 所有操作必须记录日志
- 日志不可修改和删除
- 日志保留时间不少于180天
- 敏感操作重点记录
- 登录失败超过5次锁定账号

## 业务流程

### 用户创建流程
1. 系统管理员进入用户管理
2. 点击创建用户
3. 填写用户基本信息
4. 选择所属组织
5. 分配用户角色
6. 设置初始密码
7. 保存用户信息
8. 系统发送账号通知

### 角色权限配置流程
1. 进入角色管理
2. 创建或编辑角色
3. 配置菜单权限（树形选择）
4. 配置按钮权限
5. 配置数据权限范围
6. 保存角色配置
7. 分配角色给用户
8. 用户登录后权限生效

### 组织调整流程
1. 进入组织管理
2. 选择要调整的组织
3. 修改组织信息或移动组织位置
4. 检查影响范围（成员、资源）
5. 确认调整
6. 自动更新关联数据
7. 通知相关人员

---

## 非功能性需求

### 性能要求
- 用户列表加载时间 < 2秒
- 权限配置响应时间 < 1秒
- 日志查询响应时间 < 3秒
- 支持万级用户管理

### 安全要求
- 密码加密存储（MD5+Salt或更强算法）
- 敏感操作二次确认
- 操作日志不可篡改
- 权限变更实时生效
- 登录失败锁定机制

### 可靠性要求
- 权限数据实时同步
- 日志记录不丢失
- 组织调整事务一致性
- 异常自动回滚

### 易用性要求
- 组织树支持拖拽调整
- 权限配置可视化
- 批量操作支持
- 操作向导提示

---

## 关联模块
- 所有模块：提供用户认证和权限控制
- 数据沙箱：组织维度数据隔离
- 模型实验室：用户权限控制
- 后台管理：管理员权限控制
